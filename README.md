# Resume Parser

A Flask-based Resume Parser that extracts and organizes important information from PDF resumes.

## Features

- Upload PDF resumes
- Extract resume text using PDFPlumber
- Detect candidate name, email, and phone number
- Identify common resume sections
- Organize extracted information into a clean dashboard
- Local resume processing using Python and Flask

## Technologies Used

- Python
- Flask
- PDFPlumber
- spaCy
- HTML
- CSS
